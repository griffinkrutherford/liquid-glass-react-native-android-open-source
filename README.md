# Liquid Glass for Android

An experimental open source Android liquid-glass effect powered by a custom,
deterministic membrane physics engine.

The current prototype contains a platform-light physics module and an Android
view library that captures real sibling content behind a glass surface. On
Android 13 and newer, an AGSL runtime shader applies physics-driven refraction,
blur, chromatic dispersion, tint, Fresnel edge light, and specular highlights.
Older versions receive a static translucent fallback. See [PLAN.md](PLAN.md)
for the full roadmap.

## Native usage

Place ordinary views and the glass overlay inside a `LiquidGlassScene`:

```kotlin
val scene = LiquidGlassScene(context)
scene.addView(contentBehindTheGlass)
scene.addView(LiquidGlassView(context).apply {
    effect = LiquidGlassEffect.REGULAR // CLEAR, REGULAR, or NONE
    interactive = true
    draggable = true // Optional; useful for demos and floating controls
    colorScheme = LiquidGlassColorScheme.SYSTEM
    refractionStrength = 48f
    dispersion = 6f
    blurRadius = 4f
})
```

The scene renders non-glass children into a shared offscreen bitmap without a
CPU pixel readback. Each `LiquidGlassView` samples that bitmap and a small
height texture generated by the custom membrane simulation.

`LiquidGlassView` is a `ViewGroup`, so labels, icons, and other controls can be
placed inside it. Its material API follows the useful cross-platform concepts
from [`@callstack/liquid-glass`](https://github.com/callstack/liquid-glass):
clear/regular/none effects, tint, light/dark/system appearance, animated effect
changes, and optional interactive growth and shimmer. Callstack's iOS package
wraps Apple's native `UIGlassEffect`; this project implements the observable
behavior independently with Android rendering and custom physics.

## Build

Requirements: JDK 17 and Android SDK 35.

```shell
./gradlew test assembleDebug
```

Install the demo on a connected emulator or device:

```shell
./gradlew :sample-android:installDebug
adb shell am start -n \
  io.github.griffinkrutherford.liquidglass.sample/.MainActivity
```

## Project status

This project is an early proof of concept. APIs and visuals will change before
the first stable release.
